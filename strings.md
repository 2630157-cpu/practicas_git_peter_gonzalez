# STRING
## Lo que aprendí hoy

lo que aprendi hoy es que los strings son una serie de variables 
que se encuentran en coma simple o comilla doble.

*Ejemplo*:
' Esto es un strings'
" Esto también es un strings"

También que las variables son objetos y los objetos tienen
atributos y métodos.
Un método es una acción que Python puede realizar en 
un fragmento de datos.

*Ejemplo*:
print (name.little())

Todos los métodos después va una paréntesis pq en ocasiones 
necesitan información adicional para funcionar.
